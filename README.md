# APUSH Exam 1 Review

An interactive study site for the AP U.S. History Exam 1 study guide (colonial
contact through the Constitution — 56 names & terms).

Modes: **Browse** (search + filter, mark mastered), **Flashcards**, **Quiz**
(mirrors the 25-question multiple choice), **Match**, **Time Attack**, **Era
Sort**, **Before / After** (sequencing by decade), and **Identify** practice in
the teacher's 5-W format. Progress saves in the browser; light/dark theme.

Single static page (`public/index.html`), vanilla HTML/CSS/JS. Deployed to
Cloudflare (apush.summitredeemer.cloud) via `npx wrangler deploy`.
